


Bu program, Java dili kullanılarak bir sayının faktöriyelini hesaplar.
Faktöriyel, 1’den başlayarak sayının kendisine kadar olan tüm sayıların çarpımıdır.
Program `for` döngüsü ile her adımda çarpma işlemini gerçekleştirir.
Ara adımlar ekrana yazdırılarak işlem süreci gösterilir.
Sonuç olarak, girilen sayının faktöriyel değeri ekrana yazdırılır.
